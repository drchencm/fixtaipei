跟著 4 個步驟完成連線

請先聯絡台北電腦宅修客服，待工程師提供安全碼後，再開始以下操作。

⚠️
請先確認連線對象只有在您主動聯絡台北電腦宅修，且確認正在與本店工程師聯繫時，才輸入安全碼並接受連線要求。請勿接受陌生人提供的遠端協助。
01
開啟程式

開啟 Windows 快速助手

在 Windows 電腦上按下鍵盤快捷鍵 Ctrl + Windows + Q，或點選「開始」並搜尋「快速助手」。

  • 找到「快速助手」後點選開啟。
  • 若電腦沒有此程式，可透過 Microsoft Store 搜尋「快速助手」安裝。

02
輸入安全碼

輸入工程師提供的 6 位數代碼

在快速助手的「取得協助」或「取得協助」區域，找到代碼輸入欄位。

  • 請先向台北電腦宅修工程師取得當次連線代碼。
  • 輸入 6 位數代碼後，點選「提交」。

03
允許分享畫面

確認並允許螢幕分享

畫面出現連線或螢幕分享確認視窗時，請核對連線對象，確認是您聯絡的工程師後再點選「允許」。

  • 允許後，工程師即可看到您的電腦畫面。
  • 分享畫面不代表已授予完整控制權。

SECURITY FIRST

遠端連線安全提醒

遠端協助期間，工程師可能看見您的桌面內容。請先做好基本的隱私保護。

  • 先關閉網路銀行、網購付款頁面及私人文件。
  • 不要在遠端連線期間輸入或展示重要密碼、驗證碼。
  • 安全碼只提供給您已確認身分的工程師。
  • 不確定畫面是否安全時，請先取消連線並聯絡客服。
🛡️
您始終保有連線決定權

請勿在未確認對方身分前點選允許。若不希望繼續分享畫面或控制權，可隨時結束快速助手連線。

HELP CENTER

常見問題

操作時遇到問題，可以先參考以下說明。

找不到 Windows 快速助手怎麼辦？

請先確認 Windows 已連上網路，再透過 Microsoft Store 搜尋「快速助手」並安裝。部分公司電腦可能受到資訊管理政策限制，請洽系統管理員。

輸入安全碼後無法連線？

請確認代碼是否輸入正確、是否仍在有效時間內，以及網路連線是否正常。若代碼已失效，請聯絡工程師重新提供。

工程師可以直接看到我的電腦嗎？

必須由您依照快速助手畫面提示同意分享，工程師才可看到分享的畫面；若要進一步操作，通常還需要您同意控制權要求。

我可以隨時停止遠端連線嗎？

可以。您可在快速助手中選擇離開、停止分享或關閉連線視窗，停止遠端協助。

Mac 電腦也能使用這份教學嗎？

這份教學適用於 Windows 電腦。若您使用 macOS，請先透過 LINE 或電話聯絡台北電腦宅修，確認適合的協助方式。
